# Simple GUI Calculator

A modern and responsive calculator built using **HTML, CSS, and JavaScript**. This project provides basic arithmetic operations with a clean user interface, keyboard support, and interactive button effects.

## Features

- ➕ Addition
- ➖ Subtraction
- ✖ Multiplication
- ➗ Division
- 🔢 Decimal number support
- 🧮 Parentheses support
- ⌨ Keyboard input support
- 🎨 Modern neon-themed UI
- 📱 Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
